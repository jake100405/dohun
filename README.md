# 0.3.0 · 양방향 공부 동기화

사이트와 앱은 같은 계정의 순서가 있는 변경 기록을 공유합니다. ○·△·×, 주간 완료 상태, 공부 시간(0~1440분), 메모(최대 300자)를 동기화합니다. 기존 페이지 자료는 사이트 백업에 그대로 보존하며 시간으로 변환하지 않습니다. 앱을 삭제하지 말고 같은 Apple 계정으로 업데이트하세요.

- 사이트는 열려 있으면 약 15초마다 송수신합니다. 앱은 화면이 열려 있거나 잠금화면 버튼을 누를 때 송수신합니다.
- 무료 설치 방식에서는 APNs를 쓰지 않으므로 사이트 수정이 닫힌 앱의 잠금화면에 즉시 표시되지는 않습니다. 앱 열기 또는 카드 버튼으로 최신화합니다.
- 잠금화면 ±5분 버튼, 앱의 정확한 분 입력과 메모 편집을 지원합니다. 메모 편집 링크는 앱을 엽니다.
- 카드 색은 앱에서 초록·파랑·분홍·크림을 선택합니다. OS의 실제 표시 색은 테마와 틴트 설정에 영향을 받습니다.
- 변경 항목은 서버 도착 순서대로 적용하며 기호 변경은 기존 시간·메모를 유지합니다. 삭제는 명시적으로 해당 칸 전체를 지웁니다. 오프라인 입력은 미전송 목록에 저장합니다.
- 연결키는 Keychain에만 보관합니다. 기기 간 기록은 HTTPS와 계정별 API로 전달합니다. 비밀번호를 코드나 저장소에 넣지 마세요.

## 설치
GitHub Actions의 Build free iOS trial이 시뮬레이터와 기기용 앱·확장을 빌드합니다. 생성된 unsigned IPA를 AltStore Classic으로 서명·설치합니다. 확장은 Keep App Extensions로 유지하세요. 무료 계정은 7일 이내 서명 갱신이 필요하며 AltServer PC가 필요합니다. 평소 기록과 동기화에는 PC가 필요하지 않습니다.

실기기에서 양방향 수정·오프라인 재시도·잠금화면 표시를 별도로 확인해야 합니다.
